## 🧩 About

**Combat Arms helpers** is a curated list of Combat Arms open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay, HUD customization
- **Quality-of-Life Helpers** — config manager, loadout presets, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- overlay Overlay — visualize nearby players and objectives
- HUD Customizer — adjust position, size, and opacity of on-screen elements
- Loadout Presets — save and quickly switch weapon configurations
- Recoil Notes — track and study weapon behavior in practice

### 🎨 Interface & Config
- Config Manager — import and export settings profiles
- Theme Support — light and dark overlay themes
- Hotkey Rebinding — customize all toggle keys

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Movement Helper — record and replay movement paths for study
- Aim Assist Notes — analyze crosshair placement and tracking
